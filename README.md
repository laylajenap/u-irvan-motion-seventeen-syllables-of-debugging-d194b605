Seventeen Syllables of Debugging — one haiku about debugging, three lines in
the 5-7-5 syllable shape, written to be read in one breath. Failing tests at
midnight, a breakpoint blinking in the dark, and a last line that turns the
poem back on its author.

```
Red tests at midnight
a breakpoint blinks in the dark
the bug lived in me
```

Syllables: 5-7-5. Total: 74 characters including the trailing newline (limit 200).

## Run it

```sh
python3 main.py
```

The program writes the haiku to `/output/entry.txt` (UTF-8 plain text).
